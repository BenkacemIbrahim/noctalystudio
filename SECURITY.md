# Security Policy

## Supported Versions

This project is actively maintained on the latest `master` branch.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report them privately to **benkacemibrahim1@gmail.com** with:

- A description of the vulnerability and its impact.
- Steps to reproduce or a minimal proof of concept.
- Any suggested mitigation, if known.

You can expect an acknowledgement within a few days and an update on the
resolution. Thank you for helping keep the project and its users safe.
