# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Repository documentation: README, contributing guide, code of conduct, and
  security policy.
- Editor and Git configuration for consistent formatting across platforms.
- GitHub Actions workflow running lint, typecheck, and build on every push and
  pull request.
- Issue and pull request templates, plus Dependabot configuration.

## [0.1.0] - 2026-10-25

### Added

- Personal portfolio for Ibrahim Benkacem, built with Next.js 14 and TypeScript.
- Animated hero, about, expertise, projects, testimonial, skills, process, and
  contact sections.
- GSAP ScrollTrigger and Framer Motion animations with Lenis smooth scrolling.
- Custom cursor, scroll progress indicator, and sound toggle.
- Tailwind CSS design system with a custom midnight/ivory/coral palette.
